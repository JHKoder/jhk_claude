## 리뷰어 주석 형식

```
## [type] - 제목

### 현재 코드
```python
현재 구현
```

### 문제점
간단한 설명

### 제안
개선 방안

---
```

### 예시

```
## Critical - DB 연결 닫기 누락

### 현재 코드
```python
def get_data():
    conn = sqlite3.connect(DB_PATH)
    # ...쿼리 실행
    return result
```

### 문제점
연결이 닫히지 않아 리소스 누수 발생

### 제안
```python
def get_data():
    conn = sqlite3.connect(DB_PATH)
    try:
        # ...쿼리
        return result
    finally:
        conn.close()
```

---
```

## 우선순위 레이블

- `Critical`: 머지 불가 (보안, 데이터 손실 위험)
- `Important`: 수정 필수 (기능 버그, 심각한 패턴 위반)
- `Minor`: 개선 권장 (스타일, 최적화, 리팩토링)
